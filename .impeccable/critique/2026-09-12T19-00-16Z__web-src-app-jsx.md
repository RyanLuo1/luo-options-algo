## Overall Impression

Engineering discipline is real: tokens, derived selection state, honest staleness, forgiving inputs. But the screen presents a ranked list without the evidence a trader needs to trust or compare the rank, treats a real-money save as a hyperlink, and gives the most area to a chart that shows none of the strikes. Biggest opportunity: make the table and band carry the trade's own geometry (probability, width, spot, the four zones, downside).

## What's Working

- Zero-click default selection: rank 1 open in band and chart on landing, row highlighted.
- Honest staleness signal: primary button turns amber when any control diverges from the last scan; chip removal correctly not stale.
- Forgiving numeric inputs: free-text steppers with paired string/numeric state, red-not-blocking invalid, blur clamp, tabular figures.

## Priority Issues

1. [P1] The table cannot explain its own ranking. Only Rank, Ticker, Expiration, Net Premium, Max Profit. Rank 2 can show a larger credit than Rank 1 with no justification; P(max) visible one row at a time. Fix: add P(max) column; render Max Profit as a bar with credit filled (the ratio is the score); add DTE beside week. Command: /impeccable layout.
2. [P1] Rescans and errors destroy the working view. Results unmount under loading and error (`App.jsx:448`); sort resets; chart iframe reloads; failed rescan buries prior valid results behind an undismissable banner. Fix: keep table mounted and dimmed with a progress strip; dismissable error strip above results; lift sort state into App. Command: /impeccable harden.
3. [P1] Per-share and per-contract dollars mixed without labels. Drawer min is per-share, table ×100, band mixes both. Fix: one unit per surface; live conversion under the drawer field; `/sh` suffixes in the band. Command: /impeccable clarify.
4. [P1] Save is a hyperlink with no risk framing, no confirmation, no duplicate guard. Save and Open in editor identical 12px links (`SetupDetail.jsx:92`). No `saving` flag. Band shows only upside; no max loss, collateral, breakeven. Fix: real button with disabled in-flight state; add collateral and breakeven to band; toast names what was saved with tradebook link; separate error box from toast corner. Command: /impeccable harden.
5. [P2] Chart hijacks layout and breaks on non-default tickers. Ten tickers mapped; others default to NASDAQ (JPM, XOM, LLY, V, BRK-B wrong/blank). Chart gets flexible width; ranked list pinned. Fix: pass bare symbol; chart collapsible and narrower by default; freed width to a strike ladder (K_C, spot, K_A, K_B) in the band. Command: /impeccable layout.
