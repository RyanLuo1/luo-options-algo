# docs/private/ — untracked research findings

Research findings, feature importances, and result-shaped documents live
here, **untracked** (see the `docs/private/*` rule in the repo `.gitignore`;
only this README is committed).

The split, decided 2026-07-28: **methodology stays public, results stay
private.** `docs/RANKER_SPEC.md` (the phases, gates, and honest-expectations
framing) remains in the repo. Anything that constitutes an actual discovered
signal goes here instead — the Phase C descriptive-analytics findings doc,
Phase D feature importances and walk-forward results, shadow-mode
comparisons, and any analysis whose value depends on not being public.

Nothing in this directory is backed up by git — keep copies accordingly.
